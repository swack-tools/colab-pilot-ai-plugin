pilot MCP server tools

The bundled local stdio server (scripts/colab_mcp_server.py) exposes 11 tools and the interactive dashboard resource:

ToolPurposeKey behavior
colab_dashboardLive CU & session telemetryReads colab usage, active sessions, detached jobs, keep-warm leases, and alarm state.
colab_allocate_cascadeBF16 GPU cascade allocationTries tiers in priority order (supporting prefer_gpus and high_mem), probes GPU/VRAM/RAM/BF16, and recommends safe worker counts.
colab_mount_rcloneHeadless Google Drive mountCopies local rclone.conf and mounts Drive read-only with streaming or random-seek tuning.
colab_smart_transferZero-waste archive transferAuto-mkdir direct upload ≤24 MiB, Drive staging, batch files, remote_glob downloads, and headless drive_pull extraction.
colab_launch_detachedWebSocket-proof job launcherRuns local or remote Python scripts under nohup with cwd, custom log mirroring, warm-chain cleanup, and 10-second GPU heartbeats.
colab_poll_jobREST job & log pollerFetches job status JSON, background transfers, or ad-hoc logs, processes, and output directories without holding a WebSocket open.
colab_execBounded remote commandExecutes bounded one-shot shell or Python commands (routing over SSH if kernel is busy) with optional safe PID/glob cleanup.
colab_reset_vramZombie CUDA memory flushClears tracebacks, IPython Out caches, and PyTorch CUDA cache, reporting before/after VRAM.
colab_keep_warmTimed keep-warm leaseRegisters or clears a timed lease so the Stop hook permits ending the turn intentionally.
colab_stop_allVerified VM teardownStops one named session or every active session, clears leases, and verifies 0.00/hr burn.
colab_wakeup_alarmEscalating completion alarmStarts, stops, inspects, or self-tests multi-voice macOS TTS + chirp synthesis.

Lifecycle hooks (hooks.json)

EventTriggerEnforcement
SessionStartNew session startupInjects a concise summary of active Colab VMs and current Compute Unit burn rate.
PreToolUseShell tool invocationBlocks TTY-hanging colab drivemount/auth/pay/repl, invalid --gpu tiers, and >30 MiB direct colab upload.
StopEnd of agent turnBlocks stopping while an unleased Colab VM remains allocated with no running detached job.

Interactive MCP App UI

colab_dashboard renders ui://colab-pilot/dashboard.html (plugins/colab-pilot/assets/dashboard.html) in MCP App-capable clients, displaying real-time Compute Unit balance, one-fifth monthly budget pacing, active VM assignments, detached job logs, and one-click alarm or teardown controls.

State & repository layout

  • Local state directory: ~/.colab-pilot/ stores keep-warm leases, alarm state, and cached telemetry snapshots (override with COLAB_PILOT_STATE_DIR).
  • Plugin root: plugins/colab-pilot/ holds .antigravity-plugin/, .claude-plugin/, .codex-plugin/, skills/, agents/, rules/, hooks/, scripts/, and assets/.
  • Catalog & API metadata: catalog-info.json and api/colab-pilot/tools.json provide machine-readable capability specs for the Swack Tools Marketplace.

Local CI & deterministic packaging

Validate manifests, run unit and MCP protocol tests, build the documentation site, and verify deterministic release archives locally:

python3 scripts/check_plugin.py
python3 -m unittest discover -s tests -v
python3 scripts/package_release.py dist
python3 site/build.py build/site && python3 site/check.py build/site
