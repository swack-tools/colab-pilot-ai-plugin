Setup & authentication

Install in your coding client

Colab Pilot ships multi-client manifests for Antigravity, Claude Code, Claude Desktop, and Codex, backed by a single local Python stdio MCP server.

Requirements Antigravity Claude Code Claude Desktop Codex CLI Codex Desktop Release ZIPs Colab & rclone auth

Requirements

  • Python 3.9 or later (stdlib-only MCP server and hooks; zero third-party Python packages required).
  • colab command-line tool (google-colab-cli) authenticated with OAuth 2.0 or Application Default Credentials.
  • Optional rclone configured locally for headless Google Drive pre-staging and streaming mounts.

Antigravity

Install directly from the public GitHub repository or from a downloaded release archive:

agy plugin install https://github.com/swack-tools/colab-pilot-plugin
agy plugin enable colab-pilot

Invoke /colab-pilot, /colab-train, /colab-shard-cpu, or /colab-watch, or delegate full training runs to the colab-operator subagent.

Claude Code

Add the Swack Tools marketplace and install colab-pilot inside a Claude Code session:

/plugin marketplace add swack-tools/ai-plugin-marketplace
/plugin install colab-pilot@swack-tools-community
/colab-pilot:colab-pilot Check active Colab sessions and Compute Unit burn.

Claude Desktop

Open Customize → Plugins → Add → Add marketplace → Add from GitHub, enter swack-tools/ai-plugin-marketplace, and install Colab Pilot. You can also upload colab-pilot-claude.zip from the verified releases.

Codex command-line tool

Register the Swack Tools marketplace and add colab-pilot:

codex plugin marketplace add https://github.com/swack-tools/ai-plugin-marketplace.git
codex plugin add colab-pilot@swack-tools-community

Start a new Codex session and invoke $colab-pilot, $colab-train, $colab-shard-cpu, or $colab-watch.

Codex Desktop

Open Settings → Plugins → Marketplace, choose Add → Add plugin marketplace, enter https://github.com/swack-tools/ai-plugin-marketplace.git, and install Colab Pilot.

Verified release archives

Every tagged release publishes client-specific archives (colab-pilot-claude.zip, colab-pilot-codex.zip, and colab-pilot-<version>.zip) with a verified SHA256SUMS manifest:

gh release download --repo swack-tools/colab-pilot-plugin --pattern '*.zip' --pattern 'SHA256SUMS'
shasum -a 256 -c SHA256SUMS --ignore-missing

Authenticate Colab and headless rclone

Never run interactive TTY commands such as colab drivemount or colab auth inside an agent session. Authenticate colab and configure your rclone remote once in your own terminal before delegating GPU runs:

colab auth login
rclone config   # create a Google Drive remote, e.g. "gdrive"
rclone lsd gdrive:

Once rclone.conf exists locally, colab_mount_rclone copies it to the allocated Colab VM and mounts Drive read-only with tuned VFS flags without triggering browser OAuth 2.0 prompts.
